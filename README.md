# TableTop — Переворот

Онлайн-версия игры «Переворот» для приватных комнат.

## Запуск

```bash
npm install
npm start
```

Сайт будет доступен на `http://localhost:3000`.

## Возможности

- комнаты с кодом и ссылкой-приглашением;
- 2–6 игроков;
- приватные карты;
- случайная раздача двух карт каждому;
- случайный первый игрок;
- доход 1/2/3 монеты;
- убийство за 3 монеты и переворот за 7;
- кража 2 монет;
- просмотр карты с заменой;
- обмен двух карт через добор двух;
- 10-секундное окно для «Не верю» там, где оно предусмотрено;
- Графиня блокирует убийство;
- выбор карт для вскрытия;
- автоматическая передача хода и определение победителя.


## Важно для Render
Корень проекта должен содержать `package.json`, `server.js` и папку `public` на одном уровне. Build Command: `npm install`. Start Command: `npm start`. Root Directory оставьте пустым. Сервер раздаёт `public` относительно `server.js`, поэтому структура не зависит от текущей рабочей директории.
